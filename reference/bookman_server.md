# dv.bookman module server.

dv.bookman module server.

## Usage

``` r
bookman_server(id = "_bookman", bookmark_dir = NULL)
```

## Arguments

- id:

  Unique shiny string ID. Should match the ID used in
  [`bookman_UI()`](https://boehringer-ingelheim.github.io/dv.bookman/reference/bookman_UI.md).

- bookmark_dir:

  Path to the bookmark folder of the application. Autodetected if `NULL`
