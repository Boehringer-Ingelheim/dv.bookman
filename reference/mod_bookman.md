# dv.bookman DaVinci module.

See this vignette for more details:
[`vignette("manual", package = "dv.bookman")`](https://boehringer-ingelheim.github.io/dv.bookman/articles/manual.md)

## Usage

``` r
mod_bookman(module_id = "_bookman", bookmark_dir = NULL)
```

## Arguments

- module_id:

  Unique shiny string ID.

- bookmark_dir:

  Path to the bookmark folder of the application. Autodetected if
  `NULL`.
